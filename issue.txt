  1. ADMIN/HR PANEL   — Admin aur HR ke liye complete control

Ye teeno panels ek API GATEWAY se connect hain jo karta hai:
  - Authentication (kaun hai)

Gateway ke peeche 3 services hain:
  a) AUTH & USER SERVICE  — Login, JWT, session

  c) NOTIFICATION SERVICE — Alerts, emails, push

Data storage 3 jagah hoti hai:
  - MongoDB DB   — Main database (sabhi records)
  - Redis Cache  — Fast temporary data (sessions, real-time)
  - File Storage — Attachments, documents, avatars

--- Section 3: Complete Business Flow ---

Ye flow batata hai employee ka lifecycle:
  Step 1: Admin employee create karta hai
  Step 2: Employee ko 72-hour invitation token email milta hai
  Step 3: Employee link click karke account activate karta hai + profile complete karta hai
  Step 4: Employee ACTIVE ho jata hai
  Step 5: Employee teen kaam karta hai parallel:
    - Attendance: Clock In/Out with GPS + Shift check
    - Leave: Apply karo => Balance check => Pending => Manager Approve/Reject
    - Task: Manager assign karta hai => Team validation => Task DB
  Step 6: Sab events Event Bus se manager aur admin ko jaate hain
  Step 7: Notification milti hai (WebSocket/FCM/Email/InApp)


--- Section 4: Attendance Flow (Detailed) ---

Employee Attendance ka pura flow:
  1. Employee attendance page kholta hai
  2. Clock In click karta hai
  3. System GPS + IP capture karta hai
  4. GEOFENCE VALIDATION hoti hai:
     - Agar outside => PUNCH REJECTED
     - Agar inside => aage badho
  5. SHIFT + GRACE PERIOD CHECK:
     - On Time => Status = PRESENT
     - Late => Status = LATE
  6. DB mein save hota hai
  7. Event Bus se Manager Dashboard aur Employee Dashboard update hota hai
  8. Employee Break Start kar sakta hai
  9. Break End kar sakta hai
  10. Clock Out karta hai
  11. Net hours calculate hote hain
  12. Daily Summary generate hoti hai


--- Section 5: Leave Flow (Detailed) ---

Leave ka pura flow:
  1. Employee Leave Portal kholta hai
  2. Leave Balance check hoti hai
  3. Leave Type + Dates select karta hai
  4. Medical Document Required check:
     - YES => Document Upload required
     - NO => aage badho
  5. OVERLAP CHECK (koi aur leave us date pe already approved?):
     - YES => 409 Conflict Error
     - NO => aage badho
  6. BALANCE CHECK:
     - Insufficient => 422 Error
     - Available => Create PENDING leave
  7. Leave Balance HOLD pe jaata hai
  8. Manager ko notify kiya jaata hai
  9. STAFFING CONFLICT check (team mein kaafi log absent toh nahi?):
     - Conflict ya No Conflict — dono case mein Manager decide karta hai
  10. MANAGER DECISION:
      - APPROVE => DB update + Employee notify
      - REJECT  => Reason + Employee notify

[ISSUE-001] ARCHITECTURE: MongoDB ki jagah SQLite use ho raha hai

SEVERITY: CRITICAL
